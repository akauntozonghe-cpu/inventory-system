# zaico取り込みとフリマ設定

## zaico CSVの取り込み

管理画面の「在庫データの取り込み」からzaicoのCSV（UTF-8またはShift_JIS）を選びます。Excelも先頭シートの同じ見出しに対応しています。1ファイル1,000行までで、保存は25行ずつ行います。

取り込む項目は物品名、QRコード・バーコードの値（JAN）、数量、単位、保管場所、カテゴリ（大分類）です。zaicoの在庫IDは使用しません。未設定の保管場所や期限を推測で埋めることはありません。

- JANが有効で一致先がない：通常の商品・在庫を新規登録します。
- JANが1商品に一致：商品に紐付け、在庫数量は追加・上書きしません。
- JANなし・不正・一致先が複数・廃止商品と一致・入力不備：確認待ちとして保存します。
- 同じ内容を取り込み済み：再登録しません。通信が途中で切れた場合も同じファイルで再試行できます。

確認待ちはJANなどを修正して一括再判定できます。JANなし商品は明示的に新規登録を選ぶとシステムコードを発行します。複数のJAN一致先から選ぶ場合も数量は変更しません。「対象外にする」は在庫に触れず、その行を除外します。

新規在庫は範囲が一致する作業中・中断中の棚卸にも追加されます。棚卸結果を自動入力することはありません。確認待ち・終了済みの棚卸は変更しません。移行元の数量と紐付け結果は取り込み履歴で確認できます。

## フリマ設定

「フリマの共通設定」で発送元の都道府県、発送までの目標日数、目標利益率、販売先の手数料を保存します。発送地・日数は新しく作る出品準備に保存され、既存出品の約束は変わりません。

独自の送料は全国共通、または特定の発送元都道府県に限定できます。同じ配送方法に両方の登録がある場合は発送地に一致する料金を優先します。宛先による送料の自動計算には対応していません。

手取り額は売上から手数料・送料・梱包費を引いた概算で、原価は引く前の金額です。利益はさらに原価を引きます。必要な費用が不明の場合は金額を確定表示しません。

発送目標は販売を記録した日本時間の日付から設定日数後の末日時間（23:59:59）までです。取消・差戻しでは期限も解除します。外部サービスの出品・配送期限とは別の作業目標です。

## リリース

追加したデータ定義は既存データを削除しない2件のマイグレーションです。通常のビルド手順に含まれる `prisma migrate deploy` により適用します。コード反映だけでは実際のCSVファイルは取り込まれません。
